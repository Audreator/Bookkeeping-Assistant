# 指南：电脑运行与 iPhone 使用

## 准备服务器

1. 在自己的项目根目录打开 PowerShell，确认 Docker Desktop 已运行。
2. 首次复制 `.env.example` 为私有 `.env`，填写数据库密码、JWT 密钥、`DEFAULT_USERNAME`、`DEFAULT_PASSWORD` 和可选收单令牌。已有配置不要覆盖。
3. 在项目根目录执行：

   ```powershell
   npm run db:up
   npm run db:migrate
   npm run build
   npm run start
   ```

4. 迁移与构建成功后，服务在 8787 提供网页和 API。保持服务与电脑运行；MySQL 数据保存在 Docker 卷中，不能用删除数据卷修复启动问题。

用户名与密码由自己的配置决定，当前不开放注册。真实账号、密钥、备份及服务地址只保留在自己的环境，不提交到公开仓库。

## 找到手机可访问的地址

1. 手机与服务器连接同一可互通的局域网。
2. 电脑执行 `ipconfig`，找正在使用的 Wi-Fi 或以太网适配器的 IPv4，避开未连接和虚拟网卡。
3. 在 Safari 地址栏输入 `http://<服务器IPv4>:8787`，用刚查到的数字替换 `<服务器IPv4>`。
4. 手机上不能用电脑的 `localhost`，它指向手机自己。不要把真实 IP 写进公开说明或分享截图。
5. 地址打不开时，核对服务、电脑休眠、路由器设备隔离和 Windows 防火墙的 8787 入站权限；按自己的网络范围放行。

## 登录并添加到主屏幕

1. Safari 打开应用，输入私有配置中的固定用户名和密码，登录后确认「今天」页显示。
2. 点击 Safari 分享按钮；新布局可能先打开页面菜单再选「分享」。
3. 下滑选择「添加到主屏幕」。没有这一项时可在分享菜单底部「编辑操作」加入。系统显示「作为 Web App 打开」选项时按需启用，再点「添加」。[Apple 主屏幕入口说明](https://support.apple.com/guide/iphone/bookmark-a-website-iph42ab2f3a7/ios)。
4. 从新图标打开，确认登录态、五页切换和记账。新设备登录会使旧登录会话失效，必要时在当前入口重新登录。
5. 页面/图标更新后仍缓存旧样式时，刷新并重新添加入口；移除主屏幕入口不删除服务器数据库。

电脑 IP 变化后，更新 Safari/主屏幕入口和快捷指令地址。外出使用需要自己可达的 HTTPS 服务或自己配置的安全网络，普通局域网地址在蜂窝网络下不能直接访问。

## HTTP、HTTPS 与离线能力

| 使用方式 | 当前能力 |
|---|---|
| 可信局域网 HTTP | 在线浏览与记账、快捷指令收单、普通 JSON 备份 |
| HTTPS 服务 | 在线功能及加密备份所需的 WebCrypto、安全上下文中的静态壳缓存 |
| 服务器/网络离线 | 当前不能新增交易，没有离线写入或自动补发队列 |

局域网 HTTP 会明文传输登录及收单凭据，只在自己的可信网络使用；公网部署启用 HTTPS，见 [云部署](cloud-deploy.md)。手机访问局域网 HTTP 时加密操作会给出提示，使用普通 JSON 备份并自行妥善保存。

HTTPS 不会自动增加离线账本和 Web Push；当前没有这两项实现。添加到主屏幕也不让服务器在电脑关机时继续运行。

## 设置手机收单

先照 [快捷指令指南](shortcut-ocr.md) 跑通一笔合成测试，再配置操作按钮 OCR、历史截图分享或系统支持的通知自动化。请求头用私有 `INGEST_TOKEN`，不用 App 登录密码；默认省略 OCR 的日期和时间，让原交易字段优先。
