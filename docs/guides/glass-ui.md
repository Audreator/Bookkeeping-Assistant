# 透明玻璃界面与 iPhone 16 Pro 验收

页面底色为纯浅灰，保留蓝色操作、彩色分类和图表。底部菜单采用窄胶囊轮廓，约 62px 高，每个入口 50px 高；菜单和选中圈的中心均为全透明，没有白色蒙层或毛玻璃模糊，下面的文字、线条与图案保持清晰。约 8px 的边缘带产生折射，细亮边显示轮廓。

选择圈静止时上下边缘齐平，切换时在 620ms 内滑动、膨胀、回缩、恢复，只弹一次。快速再次切换从当前形态续接，不改变菜单外框和点击范围。

导航文字为 11px、400 常规字重，沿用系统字体；iPhone 上使用系统中文字体。选中项以蓝色和选择圈识别，不增加字重；文字和图标不参与玻璃圈的缩放形变。

## 当前实现与降级

菜单与选中圈明确设置透明背景和 `backdrop-filter: none`。`GlassRefraction` 为当前 `main.app-page` 建立非交互 DOM 镜像，在独立元素上施加 SVG 位移滤镜；边缘遮罩只让约 8px 的折射带可见，中心不覆盖原页面。导航图标与文字处于清晰层中，原链接保持点击、键盘焦点和当前页标识。

镜像带 `aria-hidden`、`inert` 和 `pointer-events: none`，移除弹窗、脚本、媒体与事件属性，清空密码／文件／凭据输入，并重映射 ID、SVG 引用；不会重复挂载 React 业务组件或调用接口。位移图由圆角矩形有符号距离和正弦剖面生成，Canvas 只编码位移 PNG，不截取页面像素，也不上传页面内容。

位移图按 CSS 像素生成 1× 地图，仅尺寸、圆角或参数变化时重建；滚动与移动只校正镜像位置，版本化 filter ID 刷新缓存。页面内容变化按需更新镜像，动画期间最多连续跟踪 700ms，静止时没有持续帧循环。组件卸载会清理观察器、监听和待执行帧。

账本的横向筛选条等内部滚动区域也同步当前位置；源与副本在剪枝前按节点配对，剪枝后保留有效关系，避免移除弹窗遮罩后错配。滚动只同步相关节点，不重建整页副本，也不会由镜像自身的滚动引发循环。

减少动态效果取消形变与滑动，直接选中；减少透明度偏好仍作用于卡片、弹窗和按钮，菜单保持透明。缺少边缘遮罩支持或位移图不可用时保留透明中心和普通边框，正常导航不依赖折射效果。卡片和弹窗仍保留各自的浅色材质，不把导航的全透明规则套用到输入和表单。

这些项目提供网页对 Apple 玻璃视觉的模拟，并非 Apple 官方 iOS 27 原生控件；网页不能保证与系统原生渲染逐像素一致。

## 设备与测试口径

[Apple 的 iPhone 16 Pro 技术规格](https://support.apple.com/en-ie/121031)列出 1206 × 2622 物理像素。布局以 402 × 874 CSS 像素作为正常显示缩放下的竖屏参考，验收还应覆盖 402 × 700 的较矮可视区及横屏。Safari 工具栏、显示缩放、键盘和主屏幕模式会改变实际可用高度；应用使用 `dvh` 和 `safe-area-inset-*` 自适应。

输入字号至少 16px，防止 iOS 聚焦自动放大。菜单在底部安全区之上留 10px，膨胀峰值约 78px；页底留白和悬浮记账按钮也计算安全区。弹窗高度受可视区限制，内容可滚动；圆形操作按钮 46px。

402 × 874 是 iPhone 16 Pro 的布局模拟尺寸，不是真实 iOS Safari 运行证明；旧版预览截图也不能证明新折射效果已完成验收。每轮自动检查、预览服务、最新截图和真机结果分别记录在 [PROGRESS](../PROGRESS.md)。

## 在自己的 iPhone 上核对

1. Safari 打开可访问的服务地址，刷新到新构建；HTTPS 下旧 PWA 缓存可能需要等待更新后再刷新一次。
2. 在「今天」检查金额与圆环：退款大于日常支出时显示 0% 和正数净入账，固定分摊仍保留；真实超支保留提示。
3. 连续切换五页及快速来回切换：外框保持静止，选择圈滑动并只回弹一次；滚动账本让文字或卡片边线经过菜单，中心仍清晰，只有边缘带弯折。最后一项可滚到菜单上方。
4. 打开记账和固定分摊，检查日期、时间、房租和水费输入，唤起键盘后滚到保存按钮；竖横屏下都可以关闭和保存。
5. 通过分享菜单「添加到主屏幕」，核对新图标、顶部动态岛和底部主屏幕指示条未挡住操作。旧桌面入口图标若缓存，移除旧入口后重新添加；服务器账目不会删除。
