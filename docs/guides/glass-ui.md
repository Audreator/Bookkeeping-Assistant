# 透明玻璃界面与 iPhone 16 Pro 验收

页面底色为纯浅灰，保留蓝色操作、彩色分类和图表。底部菜单采用窄胶囊轮廓，约 62px 高，每个入口 50px 高；菜单中心有一层通透的淡灰雾，下面的文字、线条与图案仍能看清，没有背景模糊。约 12px 宽的边缘带对附近内容作局部拉长、压短，让边缘文字因形变而更难辨认。源先在圆角形状内裁切，再对同一边缘带作有界形变，避免将远处内容拖入。当前页的选择框在移动和回弹的整个 620ms 内保持同样的淡灰液态玻璃，停稳后整颗胶囊从中心到边缘都呈半透明白色毛玻璃，细亮轮廓保留。菜单折射始终显示，选择框折射只在移动和回弹时显示。

选择框静止时与菜单上下边缘齐平，切换时在 620ms 内先短暂滞后，再沿移动方向横向拉伸、前冲，随后制动、单次回弹并恢复。横向峰值约 1.64～1.70 倍、纵向约 1.16 倍，距离目标较远时前冲稍强；快速再次或反向切换从当前实际位置与形态续接，不改变菜单外框和点击范围。形变不倾斜，便于边缘折射准确跟随。

导航文字为 11px、400 常规字重，沿用系统字体；iPhone 上使用系统中文字体。选中项以蓝色和选择圈识别，不增加字重；文字和图标不参与玻璃圈的缩放形变。

菜单与移动选择框的边缘、中间共用同一层 12% 灰雾，覆盖到外沿；不另加白色描边、渐变高光或白色内阴影。停止后的选择框保留整框毛玻璃与自己的细亮轮廓。下方内容在边缘会局部伸缩，因此内容本身仍可能有明暗变化，玻璃材质色保持连续。

为消除空白区域的内环硬接缝，折射环外侧 60% 保留完整局部形变，内侧 40% 平滑淡出到真实页面。单层 PNG alpha 遮罩按圆角距离生成，形状外与中心透明；位移、灰雾色和停稳毛玻璃不变。内缘融合不是模糊滤镜。

## 当前实现与降级

菜单设置 `backdrop-filter: none`，在 `::after` 覆盖 `rgb(132 138 148 / 12%)` 淡灰雾；中心保持原内容的清晰轮廓。选择框只在停稳时使用 `#ffffff30` 白色背景（约 19% 不透明度）、`blur(14px) saturate(1.35)`，覆盖整个选择框，包括边缘；此时不叠加选择框自己的灰雾。停稳时隐藏选择框自己的清晰折射镜像，让边缘也保持毛玻璃，细亮轮廓仍可见。移动状态清除白色背景与模糊、恢复选择框折射并叠加同样的 12% 灰雾，直到本次 620ms 动画结束；快速重定向维持该材质，旧动画的结束不能提前恢复毛玻璃。导航轨道处于灰雾上方，图标与文字保持清晰，原链接保留点击、键盘焦点和当前页标识。

`GlassRefraction` 为当前 `main.app-page` 建立非交互 DOM 镜像。镜像与补底背景先进入未形变的圆角子裁切层 `.glass-refraction-clip`，使用 `overflow: hidden`；父元素再施加 `filter: url()` 与 SVG `feDisplacementMap`，最后由边缘遮罩显示折射带。这一输入裁切顺序限制了进入滤镜的源范围，不能用单纯的输出遮罩替代。SVG 位移用于改变采样位置，相关语义见 [W3C 的 feDisplacementMap 定义](https://www.w3.org/TR/filter-effects-1/#feDisplacementMapElement)。

两层折射带均为 12px，菜单/选择框的力度参数分别为 1.45/1.6，参数不等于最终屏幕像素位移。剖面在边缘带内交替压缩、拉伸，两端固定；带宽限制为不超过半宽、半高，力度限制确保采样映射单调且留在同一边缘带内，避免反折与大范围内容搬移。SVG 的 `scale` 取地图返回的受限值，和 PNG 编码一致。菜单折射始终显示，选择框折射仅在移动和回弹时显示；镜像不覆盖中心，淡灰雾不通过模糊产生。实际 Safari 光栅化与边界效果仍需真机核对。

镜像带 `aria-hidden`、`inert` 和 `pointer-events: none`，移除弹窗、脚本、媒体与事件属性，清空密码／文件／凭据输入，并重映射 ID、SVG 引用；不会重复挂载 React 业务组件或调用接口。位移图由圆角矩形有符号距离和双正弦剖面生成，Canvas 只编码几何位移与 alpha 遮罩 PNG，不截取页面像素，也不上传页面内容。

位移图按 CSS 像素生成 1× 地图，仅尺寸、圆角或参数变化时重建；滚动与移动只校正镜像位置，版本化 filter ID 刷新缓存。页面内容变化按需更新镜像，动画期间最多连续跟踪 700ms，静止时没有持续帧循环。组件卸载会清理观察器、监听和待执行帧。

账本的横向筛选条等内部滚动区域也同步当前位置；源与副本在剪枝前按节点配对，剪枝后保留有效关系，避免移除弹窗遮罩后错配。滚动只同步相关节点，不重建整页副本，也不会由镜像自身的滚动引发循环。

减少动态效果取消形变与滑动，直接选中；不支持 Web Animations 时保留 CSS 滑动，以可取消的 620ms 定时器维持移动期间的淡灰液态材质，重定向、减少动态效果或卸载会清理旧状态。减少透明度偏好使停稳后的选择框、卡片、弹窗和按钮使用更实的背景，菜单保留通透淡灰雾。停稳后的选择框在缺少背景模糊支持或启用减少透明度时使用 `#eeeeeef2` 浅色背景，减少透明度同时关闭其模糊；移动状态仍优先保持无模糊的淡灰雾。缺少边缘遮罩支持或位移图不可用时不显示折射带，菜单仍从中心到外沿保留统一淡灰雾。正常导航不依赖折射效果；卡片和弹窗保留各自的浅色材质，菜单的无模糊规则不套用到输入和表单。

这些项目提供网页对 Apple 玻璃视觉的模拟，并非 Apple 官方 iOS 27 原生控件；网页不能保证与系统原生渲染逐像素一致。

## 设备与测试口径

[Apple 的 iPhone 16 Pro 技术规格](https://support.apple.com/en-ie/121031)列出 1206 × 2622 物理像素。布局以 402 × 874 CSS 像素作为正常显示缩放下的竖屏参考，验收还应覆盖 402 × 700 的较矮可视区及横屏。Safari 工具栏、显示缩放、键盘和主屏幕模式会改变实际可用高度；应用使用 `dvh` 和 `safe-area-inset-*` 自适应。

输入字号至少 16px，防止 iOS 聚焦自动放大。菜单在底部安全区之上留 10px；选择框的形变可以伸出外框，但不改变实际触控区域，页底留白和悬浮记账按钮也计算安全区。弹窗高度受可视区限制，内容可滚动；圆形操作按钮 46px。

402 × 874 是 iPhone 16 Pro 的布局模拟尺寸，不是真实 iOS Safari 运行证明；旧版预览截图也不能证明新折射效果已完成验收。每轮自动检查、预览服务、最新截图和真机结果分别记录在 [PROGRESS](../PROGRESS.md)。

## 在自己的 iPhone 上核对

1. Safari 打开可访问的服务地址，刷新到新构建；HTTPS 下旧 PWA 缓存可能需要等待更新后再刷新一次。
2. 在「今天」检查金额与圆环：退款大于日常支出时显示 0% 和正数净入账，固定分摊仍保留；真实超支保留提示。
3. 连续切换五页及快速来回切换：外框保持静止，选择框左右拉伸、方向性前冲并只回弹一次；快速反向时衔接当前形态，整个移动和回弹过程保持无模糊的淡灰液态材质，最后恢复原尺寸时整颗选择框连同边缘一起呈毛玻璃，选择框边缘不再露出清晰文字。滚动账本让文字或卡片边线经过菜单：选择框之外的菜单中心呈淡灰雾但内容仍清晰，边缘文字应局部拉长、压短；核对是否出现远处内容拖入、反折或重影，导航文字始终清晰。最后一项可滚到菜单上方。
4. 打开记账和固定分摊，检查日期、时间、房租和水费输入，唤起键盘后滚到保存按钮；竖横屏下都可以关闭和保存。
5. 通过分享菜单「添加到主屏幕」，核对新图标、顶部动态岛和底部主屏幕指示条未挡住操作。旧桌面入口图标若缓存，移除旧入口后重新添加；服务器账目不会删除。
