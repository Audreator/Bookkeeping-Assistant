# 使用指南

## 在手机上开始

按 [手机运行指南](local-preview.md) 启动服务，Safari 打开自己可访问的地址，使用私有 `.env` 中的 `DEFAULT_USERNAME` 与 `DEFAULT_PASSWORD` 登录。当前无需注册；分享菜单「添加到主屏幕」可建立独立入口。

服务器保存数据，电脑关机、休眠或网络不可达时不能新增记录。当前没有离线写入与补发队列。公网部署用 HTTPS；手机局域网 HTTP 可使用普通 JSON 备份，加密备份需 HTTPS 安全上下文。

## 五个页面

| 页面 | 用途 |
|---|---|
| 今天 | 今日可花（固定支出已从本期预算扣除）、本期概况、近期交易与记账入口 |
| 账本 | 搜索/筛选，查看日期与秒级时间，编辑/删除支出及退款 |
| 规划 | 月/周预算、月历、单日预算与调整记录 |
| 统计 | 本月支出与收入、分类占比、每日支出及商户统计 |
| 设置 | 分类、固定支出、CSV 导入、备份及账号 |

省下的钱按日结转；今日支出扣减可花额，超支产生负结余，退款补回额度。本期内未支付的固定支出先从当期总预算中整体扣除，其余日期按扣除后的金额重新均摊；账单实际支付时记一笔支出，预留同时释放，不会重复扣。单独设预算当天显示设定额减当日支出，其余日期重新均摊；总预算不足时会提示，可修改或取消。

退款应按实际本次退款金额和日期记独立记录，不把原支付直接改成普通收入。当前交易类型只有支出和退款：收单里的收款、转入、工资等进账通知会记为一笔退款，需要时自行在账本核对。

## 交易日期与时间

手工记账可填写日期、时间；历史记录、CSV 或邮件没有原时间时可显示「时间未记录」。分钟来源补 `:00`，末尾零不表示真实秒数。

自动收单优先显式 `date/time`，其次原文交易字段，缺失时保存接口接收日期和秒级时间。接收时间是网络到达服务器的时刻，可能晚于支付/退款。OCR、通知默认省略这两个参数可保留原文优先级；历史内容缺日期时应补确认后的日期，不能无条件覆盖成现在。

## 快捷指令与支付自动化

照 [逐动作快捷指令指南](shortcut-ocr.md) 完成：

1. 用合成文本跑通 POST JSON 请求：键 `text`、值为文字，标头 `x-ingest-token` 为自己的私有令牌。
2. 将输入替换为操作按钮截图 OCR，或从相册分享一张历史截图。
3. 系统具备通知触发器时先确认通知输入的「信息/正文」文字，再调用接口；若是对象，用文字属性或提取文字动作，`400` 时检查 `inputShape`。
4. 分别验证支付、退款、重试与失败状态；同一事件保持稳定 `eventId`，退款和原支付使用不同 ID。

Apple 的 iOS 27 指南列出通知触发器，可按 App 和通知字段筛选；这是公开版本能力说明，实际菜单、原文完整性、锁屏与退款覆盖仍按自己的设备验证。[Apple 官方事件触发器](https://support.apple.com/guide/shortcuts/apd932ff833f/10.0/ios/27)。项目已有匿名银行通知模板回归及手机正文 POST 成功的匿名结论，不能据此保证所有来源均已验证。

成功响应 `duplicate: false` 表示新建，`duplicate: true` 表示已有记录；`422` 表示文本不足以确定交易，`400` 表示参数/输入结构不合要求。网络超时先查账本，再用原事件 ID 重试。

银行「入账收入」无法区分退款、工资与其他进账，收单会统一记为退款。自己已确认类型与准确金额时可调用结构化接口，完整字段见 [收单 API](ingest-api.md)。App 打开、Wallet tap 或普通聊天提示也不等于已经支付成功。

## 邮件、账单与备份

服务器 IMAP 可异步处理符合条件的银行邮件，需配置私有授权码、确认银行提供分笔通知并校准真实模板，见 [QQ IMAP](qq-imap.md)。固定支出提醒在打开首页时显示；当前没有 Cloudflare 中转或 Web Push。

微信/支付宝 CSV 在自己的设备解压后，设置 → 数据 → 账单对账导入 → 核对预览再导入，见 [账单导出](bill-export.md)。不同来源不能保证完全自动对账，导入后抽查原支付、退款与重复。

设置可导出普通或加密备份；恢复为追加式 ID 映射，重复导入前确认原数据。不要把备份、账户信息、通知正文或带令牌的快捷指令提交到公开仓库。

## 常见问题

| 问题 | 处理 |
|---|---|
| 忘记/修改密码 | 修改私有配置的 `DEFAULT_PASSWORD` 后重启服务，数据保留 |
| 多台设备登录 | 当前只允许一个会话，新登录使旧会话失效 |
| 连续密码错误 | 5 次错误冷却 5 分钟 |
| 重新登录条件 | 30 天 token 可随请求续期；闲置过期、退出或新设备登录仍可能失效 |
| 换手机 | 原服务器可重新登录；服务器迁移前备份数据库 |
| 通知不完整 | 操作按钮 OCR/手工参数补录；公开反馈只附去隐私的结构或合成样本 |
| HTTP 下无法加密备份 | 使用普通 JSON 并私密保存，或改用 HTTPS |
