# 主屏幕图标维护

最终源文件为 `public/logo.svg`。图形由圆角账本、三条记录线和右下方蓝色「＋」组成；书脊与记录线保留记账识别，蓝色镜片表示新增一笔。主体使用黑白灰，强调色为 `#0885FA`，在同一蓝色色相内以轻微明暗渐变表现玻璃折光。

当前设计采用二维 SVG 图形：中性深灰账本、透明白色高光与细边缘反光。高光被裁剪在账本和蓝色镜片内部，不依赖照片、纹理、透视或立体钱包。所有内容均由路径、圆形、圆角矩形和 SVG 渐变构成，便于维护与缩放；没有外部图片、字体或滤镜依赖。早期纯色方案和概念图只作历史参考，当前源文件为液态玻璃版本。

画布为 512×512，`#F3F3F3` 不透明中性背景覆盖全画布，SVG 内的透明度仅用于叠加高光。PNG 导出仍具有完整背景，避免主屏幕图标出现黑底。平台负责主屏幕圆角与遮罩，源文件不预先裁切外框。

Apple 与普通 PWA 图标将 `app-mark` 分组围绕 `(256,256)` 放大到原来的 **1.36 倍**。整组范围约为 `x=84.6…443.7`、`y=57.4…454.6`，主体约占画布70%宽、78%高；减少主屏幕留白，三条记录与蓝色「＋」也同比放大。高光只作细节，不承担识别信息。

maskable 图标单独按原始比例渲染，避免用中央安全圆限制 iPhone 图标的主体大小。其账本范围仍为 `x=130…376`、`y=110…402`，蓝色镜片中心 `(330,337)`、半径60，背景分隔圆半径64；重要图形留在中央半径204.8的安全圆内。两类图标具有相同标识和颜色，布局比例由目标平台区分。

`node scripts/generate-icons.cjs` 使用当前依赖链里的 sharp，从同一个源文件生成 PNG 与 ICO，并同步 `favicon.svg`。Apple 图标为180×180，普通PWA图标为64/192/512，maskable图标为512，favicon为32。脚本只对maskable导出替换 `app-mark` 的比例；缺少该分组会报错，避免误把放大图用于安全区遮罩。更新SVG后必须重新生成图标，避免桌面入口与页面品牌不同步。

生成文件检查、生产构建、服务操作与真机主屏幕效果分别记录在 [PROGRESS](../PROGRESS.md)；源文件更新不代表真机已经验证。图标本身无需修改预算、交易或收单逻辑。

更新图标后重新构建并部署新静态文件。Apple 图标链接版本参数在 `index.html`；旧主屏幕入口仍有缓存时，从Safari分享菜单重新添加入口。账目保存在服务器，不会因移除桌面入口而删除。
